## 🇧🇷 Português (Brasil)

### Descrição Curta (GitHub About)
🛡️ Integre o SentinelOne ao GLPI 11 com dashboard, agentes, ameaças, tickets automáticos, alertas por e-mail e cobertura de endpoints em uma interface moderna.

### Descrição Média
🛡️ **SentinelOne para GLPI 11** centraliza agentes, ameaças, cobertura de endpoints e alertas de segurança direto no GLPI. Sincronize dados da API SentinelOne, acompanhe o status dos endpoints, crie tickets automaticamente para ameaças e monitore a saúde dos agentes com uma experiência visual moderna e objetiva.

### Descrição Longa
🚀 **SentinelOne GLPI Plugin** leva dados de segurança de endpoints para dentro do GLPI 11, conectando inventário, ameaças e operação de suporte em uma única visão.

✨ Funcionalidades:
- 🧭 Dashboard operacional com métricas, saúde dos agentes e ameaças recentes
- 💻 Sincronização de agentes SentinelOne com computadores do GLPI
- 🔎 Diagnóstico de agentes sem vínculo e computadores sem agente
- 🚨 Sincronização de ameaças com severidade e contexto técnico
- 🎫 Criação opcional de tickets automáticos sem duplicidade
- 🛡️ Registro do SentinelOne como antivírus nativo do computador no GLPI
- 📬 Alertas por e-mail para ameaças críticas e problemas de agente
- 🔗 Deep links opcionais para a console SentinelOne
- ⚙️ Configuração guiada com teste de conexão e presets de API
- 🔐 Permissões dedicadas por perfil GLPI

🎯 Ideal para equipes de TI, segurança e service desk que precisam enxergar a postura dos endpoints, responder incidentes mais rápido e manter o inventário do GLPI conectado à operação de segurança.

## 🇺🇸 English

### Short Description (GitHub About)
🛡️ Integrate SentinelOne with GLPI 11 using dashboards, agents, threats, automatic tickets, email alerts, and endpoint coverage in a modern interface.

### Medium Description
🛡️ **SentinelOne for GLPI 11** brings endpoint security data directly into GLPI. Sync SentinelOne agents and threats, monitor endpoint health, create incident tickets automatically, send critical alerts by email, and track coverage from a clean operational dashboard.

### Long Description
🚀 **SentinelOne GLPI Plugin** connects endpoint security, asset inventory, and service desk workflows inside GLPI 11.

✨ Features:
- 🧭 Operational dashboard with health, coverage, and recent threats
- 💻 SentinelOne agent synchronization with GLPI computers
- 🔎 Diagnostics for unlinked agents and unprotected computers
- 🚨 Threat synchronization with severity and technical context
- 🎫 Optional automatic ticket creation with duplicate protection
- 🛡️ SentinelOne registration as the native antivirus entry on GLPI computers
- 📬 Email alerts for critical threats and agent health issues
- 🔗 Optional deep links to the SentinelOne console
- ⚙️ Guided configuration with connection testing and API presets
- 🔐 Dedicated GLPI profile permissions

🎯 Built for IT, security, and service desk teams that need clear endpoint visibility, faster incident response, and a stronger connection between GLPI inventory and security operations.
